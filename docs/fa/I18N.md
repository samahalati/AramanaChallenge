# پشتیبانی از زبان (فارسی‌محور، با کلید انگلیسی)

**سند رسمی چالش:** فایل PDF به انگلیسی است و برای رابط کاربری، مستندات، README یا داده هیچ الزامی دربارهٔ زبان ندارد. بنابراین فارسی مجاز است؛ پلتفرم **به‌طور پیش‌فرض فارسی است (راست‌به‌چپ، تاریخ جلالی، ارقام فارسی)** و یک **کلید EN/فا** دارد تا ارزیاب‌های انگلیسی‌زبان هم بتوانند آن را بخوانند. مستندات هر دو زبان در `docs/` و `docs/fa/` موجود است.

## قاعدهٔ طراحی: ذخیرهٔ انگلیسیِ متعارف، بومی‌سازی هنگام نمایش

| لایه | روش |
|---|---|
| پایگاه داده | توکن‌ها و قالب‌های انگلیسیِ متعارف (`failed_login_burst`، `critical`، عنوان هشدارها…). امتیاز، سطح، وضعیت و منطق قواعد هرگز به زبان وابسته نیست. |
| زبان درخواست | `core.middleware.LanguageMiddleware` هدر `Accept-Language` را در یک `ContextVar` می‌گذارد؛ پاسخ‌ها `Content-Language` دارند. |
| متن هشدار | کاتالوگ فارسیِ متن‌های تولیدشده توسط سامانه در `detection/i18n.py` (پایتونِ خالص) و اعمال آن هنگام سریال‌سازی در `monitoring/localize.py`. |
| واژگان | `core/i18n.TERMS` (enumها، نقش‌ها، مجوزها، کلیدهای شواهد) از `GET /api/meta/labels` سرو می‌شود و SPA پیش از اولین رندر آن را بارگذاری می‌کند. |
| خطاهای API | `core/errors.exception_handler` پیام‌ها را مرکزی ترجمه می‌کند. |
| داده‌ی دمو | `seed_demo --lang fa` (پیش‌فرض) نام‌های مستعار و متن‌های آزاد فارسی می‌سازد؛ `--lang en` مجموعه‌داده‌ی انگلیسی را نگه می‌دارد. |
| فرانت‌اند | `src/lib/i18n.js` (`t()`، `pretty()`، `num()`، `d10/dt` جلالی)، دیکشنری `src/lib/fa.js`، RTL با ویژگی‌های منطقیِ CSS، فونت وزیرمتن (ارقام فارسی). دستور `npm run check:i18n` اگر کلیدی ترجمه نداشته باشد شکست می‌خورد. |

## دستیار LLM به فارسی
بستهٔ شواهد، پرامپت، جایگزین قطعی، دروازهٔ ورودی و شش نگهبان خروجی همگی فارسی را پشتیبانی می‌کنند. پاسخ‌ها پیش از بررسی نرمال می‌شوند (`pack.fold`: NFKC، ارقام فارسی ← لاتین، حذف ZWNJ/اعراب، یکسان‌سازی ي/ك) تا ترفندهای هم‌شکل/نویسهٔ نامرئی و ارقام فارسی نتوانند بررسی عدد، لحن و هویت را دور بزنند. مجموعهٔ red-team هر دو زبان را آزمایش می‌کند (`python manage.py evaluate_llm`).

## محدودیت‌های صادقانه
* نگهبان‌ها الگومحورند؛ بازنویسی‌های فارسیِ خارج از الگوها می‌توانند رد شوند. مجموعهٔ آزمون را خودم نوشته‌ام؛ پسرفت را می‌سنجد، نه استحکام در دنیای واقعی.
* هیچ مدل واقعی اجرا نشده (کلید API در محیط ساخت نبود)؛ کیفیت پاسخ فارسی یک LLM واقعی اندازه‌گیری نشده است.
* انتخابگر تاریخ مرورگر میلادی می‌ماند؛ همهٔ تاریخ‌های نمایش‌داده‌شده جلالی (UTC) هستند.
* متن آزادی که کاربر تایپ می‌کند همان‌طور که هست نمایش داده می‌شود (ترجمه نمی‌شود).
