# طراحی بصری: «خاک و زیتون»

[English](../DESIGN.md) · **فارسی**

ظاهری گرم و آرام برای یک محصول سلامت روان: سطح‌های کرم، رنگ اصلی زیتونی و تأکید آجری. فارسی‌محور (راست‌به‌چپ) با حالت کامل انگلیسی. همه‌چیز با متغیرهای CSS در `frontend/src/styles.css` کنترل می‌شود؛ پس تغییر پوسته یعنی تغییر چند مقدار.

## نام و نشانک
نام محصول **آرامانا** است (انگلیسی: *Aramana*). نشانک یک برگ است (رشد و مراقبت): `frontend/src/components/Logo.jsx` (SVG درون‌خطی با رنگ‌های پوسته) و `frontend/public/favicon.svg`.

## حروف‌نگاری
| نقش | فارسی | انگلیسی / لاتین |
|---|---|---|
| عنوان‌ها | نسخ نوتو (۷۰۰) | Georgia با پشتیبان serif |
| متن و کنترل‌ها | نوتو سنس عربی (۴۰۰/۶۰۰/۷۰۰) | فونت سیستم |
| رقم‌ها (حالت فارسی) | **همه‌جا رقم فارسی**: بازه‌ی ارقام با وزیرمتن FD جلوی هر دو فونت می‌آید (`unicode-range` در `styles.css`)؛ پس ارقام لاتینِ داده‌ی API هم به شکل ۰۱۲۳ کشیده می‌شوند |

فونت‌ها از npm بسته‌بندی می‌شوند (`@fontsource/noto-*`، `vazirmatn`): بدون درخواست بیرونی، آفلاین کار می‌کند و سیاست امنیتی سخت‌گیرانه با `font-src 'self'` می‌ماند.

## شکل و فاصله
شعاع کارت‌ها ۱۸ px، کنترل‌ها ۱۲ px، قرص‌ها ۹۹۹ px؛ حداقل ارتفاع لمسیِ ۴۴ px برای کارهای اصلی؛ چیدمان راست‌به‌چپ با ویژگی‌های منطقی CSS (`inline-start/end`) است تا یک stylesheet هر دو جهت را پوشش دهد.

## تغییر ظاهر
متغیرهای بالای `frontend/src/styles.css` (`:root` و بلوک `@media` تیره)، برگ در `Logo.jsx` و `public/favicon.svg`، و ایمپورت فونت‌ها را ویرایش کنید. متن دکمه‌ها و صفحه‌ها جداست: `frontend/src/lib/fa.js` (ر.ک. [I18N.md](I18N.md)).

پیشنهادهای طراحی که به این انتخاب رسید (سه جهت، گزینه‌های متن دکمه‌ها و نمونه‌های نشانک) بررسی شد و جهت «خاک و زیتون» انتخاب شد.
